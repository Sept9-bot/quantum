这是我的文件管理学习仓库，用于练习使用 VS Code 编辑文件、使用 Git 保存修改历史、使用 GitHub 同步版本，以及用 AI 辅助管理文件。

- [Git与AI文件整理笔记.md](学习/Git与AI文件整理笔记.md)：记录 Git 提交与推送的区别，以及 AI 辅助整理文件的流程。

## 操作流程

修改文件 → 检查差异 → 暂存 → 提交 → 同步更改。

1. 修改文件并保存。
2. 在 VS Code 源代码管理中查看差异，确认修改符合预期。
3. 暂存本次需要记录的文件。
4. 填写提交说明并提交，在本地保存一个版本。
5. 同步更改，拉取 GitHub 上的远程更新，再推送本地提交。

## AI 使用规则

- 修改前明确操作范围、目标和需要保留的内容。
- 修改后检查文件内容和差异，确认结果符合要求。
- 未经要求，不删除文件。
- 未经要求，不提交或推送。
